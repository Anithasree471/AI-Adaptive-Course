# AI Adaptive Course Builder

## Overview
AI Adaptive Course Builder is a web-based learning platform that automatically generates structured educational content based on the topic entered by the user. The system uses Artificial Intelligence to create personalized learning modules that include notes, tutorial videos, assessments, coding assignments, and reference articles.

The application is designed to simplify the learning process by reducing the time required to search for educational resources across multiple platforms. Users can easily access organized learning materials through a user-friendly interface.

---

## Features
- AI-powered course generation
- Personalized learning modules
- Tutorial video integration using YouTube API
- Assessments and coding assignments
- Reference article recommendations
- User authentication system
- Learning progress tracking
- Admin dashboard for monitoring user performance
- MongoDB database integration

## How It Works
1. User enters a topic to learn.
2. The system generates structured course content using AI.
3. Relevant tutorial videos and articles are fetched automatically.
4. Users can complete assessments and coding tasks.
5. Learning progress and scores are tracked through the dashboard.
